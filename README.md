# כמה אתה יודע? — משחק טריוויה

משחק אינטראקטיבי עם קוביות לחיצה על הישגי **הציונות הדתית** בכלכלה ובביטחון.

פרויקט נפרד לחלוטין מבוט ההישגים.

## הרצה

פתחו את `index.html` בדפדפן, או מתוך התיקייה:

```bash
npx --yes serve .
```

ואז היכנסו לכתובת שמוצגת בטרמינל.

## עריכת שאלות

השאלות נמצאות ב־`questions.js`. כל שאלה כוללת:

- `question` — נוסח השאלה
- `options` — 4 קוביות (`icon` + `label`)
- `correctIndex` — אינדקס התשובה הנכונה (0–3)
- `fact` — משפט חיובי שמוצג אחרי הבחירה

התוכן מבוסס על הקובץ `עדכון אתר הישגין.xlsx` מתיקיית GAME.
